Uso no navegador

Colar pelo inspecionar

Use este metodo quando quiser rodar o script apenas na pagina aberta, sem instalar extensao.

Passo 1 Abra a pagina alvo

Entre no sistema ou site onde o script deve atuar. Aguarde a pagina carregar completamente.

Passo 2 Abra o inspecionar

Pressione F12 ou Ctrl + Shift + I e escolha a aba Console.

Passo 3 Liberar colagem

Se Chrome ou Edge bloquear a colagem, digite allow pasting no Console, pressione Enter, e depois cole o codigo.

Passo 4 Execute o codigo

Cole o .js copiado, pressione Enter e use o painel que o script abrir na propria pagina.

Execute apenas em paginas onde voce tem permissao para automatizar acoes. Antes de iniciar um lote grande, rode um teste pequeno e confira o resultado.
